Ficha Técnica: Visual Studio Code

Documento descriptivo sobre el editor de código desarrollado por Microsoft.

Definición y Concepto

Un VS Code es una herramienta esencial para el desarrollo de software moderno.

Visual Studio Code es un IDE ligero pero potente que permite editar, depurar y gestionar proyectos de software.

Datos de Lanzamiento

Fue anunciado por Microsoft en la conferencia Build y su lanzamiento oficial fue el 29 de abril de 2015.

Actualmente se considera la versión v2nd dentro de la evolución de grandes herramientas de edición corporativa.

Accesos Directos y Comandos

Para guardar rápidamente tus cambios en Windows/Linux, presiona la combinación Ctrl + S.
